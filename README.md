# Gameglory · Геймдизайнер (эталонные GDD и питчи) · «Питч по закреплённому анализу»

Тестовое задание на позицию «Геймдизайнер (эталонные GDD и питчи)» (стажёр / джун) в проекте Gameglory, Bear Head Studio.
Нужно по одному из двух закреплённых анализов идеи написать эталонный питч для издателя или концепт-документ
для гранта ИРИ, где каждое число опирается на анализ, составить чек-лист хорошего питча и проверить
по нему питч, сгенерированный языковой моделью.

Задание — в документе
[`Тестовое_задание_Game_Designer.pdf`](Тестовое_задание_Game_Designer.pdf).

> Данные синтетические: названия игр, студий и издателей, числа и описания сгенерированы и не описывают
> реальные продукты. Это не выгрузка Steam, датасет не связан с Valve. Совпадения с реальными названиями случайны.

## Состав пакета

| Путь | Что это |
|---|---|
| `Тестовое_задание_Game_Designer.pdf` | задание: задача, входные данные, что сделать, как сдать |
| `analyses/A1_alchemists_coop_deckbuilder.md`, `.json` | закреплённый анализ `A1`: кооперативный рогалик-декбилдер «Котёл на двоих» |
| `analyses/A2_sky_islands_cozy_farm.md`, `.json` | закреплённый анализ `A2`: уютная ферма на летающих островах «Ветряная долина» |
| `llm_pitch_A1.md` | питч для издателя, сгенерированный моделью по анализу `A1` |
| `recipients.md` | чем отличаются документы для издателя и для гранта ИРИ |
| `review_template.md` | шаблон таблицы для разбора LLM-питча |

## Как устроен анализ

`.md` и `.json` содержат одни и те же данные; в JSON есть ещё описания похожих игр (`short_description`).

| Раздел | Что внутри |
|---|---|
| Идея, автор | текст идеи, теги, команда, движок, стадия, срок, бюджет, цена |
| Похожие игры | top-10 из каталога: цена, отзывы, доля положительных, оценка выручки, сходство |
| Ниша | число игр, релизы по годам (2026 — неполный год), цены, отзывы, частые теги |
| Выручка ниши | метод и дата оценки, сколько игр без оценки, квартили, медиана, доля ниже $1 000 |
| Прогноз | число релизов в нише на 12 месяцев: точка и 80%-интервал, модель и её ошибка |
| Разбор идеи | оценки модели по шести критериям с комментариями и точками роста |
